# SoulStone visual identity

Original generated artwork inspired by the supplied Vibrant Soul channel reference: midnight navy, electric violet, cyan highlights and a masked companion. The brand is presentation only; it does not change the bot's Minecraft login or owner.

- `SoulLantern.png`: voxel soul lantern used in the header, chat and macOS Dock icon. Cyan soul flame, obsidian frame and amethyst corners.
- `Logo.png`: rejected VS monogram, retained as iteration history; not used by the interface.
- `Soul.png`: original mascot artwork, retained for future larger illustrations.
- `World.png`: decorative castle landscape. It is concept art, not a live view of the server.
- Generated using the built-in image tool. Its exact model variant was not selectable or exposed. No user API key was used.

`companion/scripts/build.py` copies these assets into the application bundle and packages the icon with macOS tools. The bundle identifier and executable path remain stable for existing settings and credentials.
